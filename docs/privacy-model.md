# Privacy Model

## Public Repository

This repository should contain:

- Plugin manifests
- Reusable skill instructions
- Reference guidance
- Sanitized templates
- Sanitized examples
- Setup documentation

## Private Workspace

Keep these files private and out of version control:

- Real CVs
- Recommendation letters
- Job ads
- Prior cover letters
- Generated raw drafts
- Generated final letters
- Any identifying personal data

## Recommended Split

Use this plugin from `my-applications/` or a separate private application workspace with folders such as:

- `cv/`
- `examples/`
- `recommendations/`
- `ads/`
- `output/raw/`
- `output/final/`

The plugin provides the workflow. The private workspace provides the sensitive data.

## Before Publishing

Check the full repository, including git history, for private material before pushing publicly.
